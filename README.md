# Générateur vidéo IA

Application web de génération vidéo à partir d’un texte ou d’une image.

## Fonctionnalités prévues
- Texte vers vidéo et image vers vidéo
- Formats 9:16, 16:9 et 1:1
- Durée configurable de 1 à 180 secondes
- Interface React/Vite et API Python/FastAPI

## État du projet
Le dépôt démarre avec le socle documentaire. La génération vidéo réelle devra être connectée à un fournisseur ou à un modèle vidéo compatible. L’application ne doit pas présenter une vidéo simulée comme une génération réelle.

## Architecture prévue
- `frontend/` : interface React avec Vite
- `backend/` : API Python avec FastAPI
- Génération vidéo : intégration ultérieure d’un modèle ou fournisseur compatible

## Démarrage
Les instructions de lancement seront complétées lors de l’ajout des fichiers frontend et backend.
